# Q6 - Which status is right? (oracle / ground truth)

Asker: Nathan Pierce (Northwest Production). Field-wide, not just NW. Today = 2027-01-15.
Question: "For which wells do the latest inspection and the operator notes disagree about whether the well is producing oil? For each, what is its real status right now, and why?"

## Rule that decides it

`operations-sop-rev2.md` **OPS-3 (Status evidence precedence)**: a well's current status comes from the more recent of (a) its latest inspection reading (producing / not producing by the well-type manual, **after any `data_correction`**) and (b) its latest operator note saying the well was **shut in or restarted**.
- Shut-in note more recent than the latest inspection -> **Not producing (shut in)**, even if the inspection read producing.
- Restart note more recent than the latest inspection -> **Producing (unconfirmed)** until an inspection confirms it.
- Other operator notes (gas odor, bypass, noises, "pumping normally", equipment remarks) do **not** change status.

Producing test per reading (wellhead - ambient >= threshold): T200 >= 15 C (`T200.md` 9.3), T350 >= 20 C (`T350.md` section 3), **T500 >= 25 C** (`T500.md` section 3). Use the well's type on the inspection date (`type_history`).

Latest inspection per well = latest `inspected_at` (late-entered -B inspections INS-0017-B001, INS-0024-B001, INS-0077-B001 are older than each well's latest weekly inspection, so they change nothing). All latest inspections are dated 2027-01-14 except 19 wells whose latest is 2026-11-19..2027-01-07 (incl. plugged wells).

4. Late-entered -B inspections are positioned at file end but dated earlier; they never are the "latest" here.
5. Restart notes on four wells claim a repair finished while the maintenance record still shows an in-progress job (interim report, planned `completed_at` after today): reason for the word "unconfirmed" - flag this inconsistency.
6. Scope is the whole field (SW-23 x5, NW-12 x3, SE-32 x2 in the core 10).
